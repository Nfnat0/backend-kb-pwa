# 基礎編を独立した学習モードとして追加する

2026-09-23

## 決定

SwiftUIアプリおよびWeb版PWAに「基礎編」を追加し、既存の学習体験を「実践編」として維持する。教材、進捗、復習予定、ブックマーク、統計、途中セッションをモード別に管理する。基礎編教材はアプリ・PWAに同梱し、学習データも端末内に保存する。バックアップには両モードの記録を含め、旧形式の実践編バックアップの読込を引き続き受け付ける。

## 理由

初学者向けに語彙や説明の順序を変えた学習を、実務者向けの設計判断問題へ混在させると、進捗・復習間隔・統計の意味が崩れる。別の状態として保持すれば、既存の実践編履歴をそのまま残しながら、ホームから切り替えてそれぞれの学習を再開できる。教材の同梱は完全なオフライン利用と、参照元の内容とのバージョン整合性を保つ。

## 影響

- 既存の実践編保存領域と過去の履歴を保持する。
- 基礎編の復習は問題単位でなくレッスン単位となる。
- 新しいバックアップ形式は両モードのデータを置き換える。以前の実践編のみのJSONは実践編として復元し、基礎編は空の状態にする。
