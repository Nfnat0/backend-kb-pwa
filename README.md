# Backend Knowledge Base PWA

バックエンドの仕組みと設計判断を、自分の言葉で説明するための日本語学習アプリ。iPhoneのホーム画面から利用でき、初回保存後は全教材をオフラインで読めます。

- 全24トピック、説明問題96問＋選択問題24問
- 原文の全11章、表・コード・Mermaid図28個を収録
- 自己評価に応じた間隔反復、途中再開、ブックマーク、学習統計
- ログインなしの端末内保存、JSONバックアップの書き出し・復元

## 開発

Node.js 20.19以降または22.12以降。

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

オフライン動作は開発サーバーではなくビルド後のプレビュー、またはHTTPS公開先で確認してください。初回は通信が必要です。設定画面の「オフラインで学習できます」が保存完了の目印です。

## 教材

出典: https://nfnat0.github.io/backend-knowledge-base/

元ソース: https://github.com/Nfnat0/backend-knowledge-base/tree/c881de6/docs/topics

取得日: 2026-09-23。`public/materials/`は元のMarkdownを保持します。`scripts/editorial.json`にトピックごとの問いと選択問題、`scripts/content.mjs`に原文との対応付けがあります。`npm run build`で120問と全教材を再生成します。

問い・解説内容から問題IDの版を生成し、意味が変わった問題に過去の習得結果を誤って引き継がないようにしています。旧問題の履歴はバックアップと累計回答数に残り、現行問題の習得率や復習対象とは分けます。

## 保存と復習

学習記録は同じ配信元・ブラウザ内のlocalStorageに保存されます。クラウド同期はありません。Safariとホーム画面アプリの保存領域が異なる場合があるため、利用するアプリ側でバックアップしてください。

- 説明できない／選択不正解: 翌日
- 一部説明できる: 3日後
- 説明できる／選択正解: 7→14→30→60日（上限60日）
- 期限前の自主練習: 回答を記録し、予定は変更しない
- 日付: 端末の現地時間、午前0時区切り

復元ファイルは検証してから、確認画面を経て置き換えます。端末の容量不足・ブラウザデータ削除に備え、定期的にバックアップを書き出してください。

## 公開

`dist/`はサブディレクトリに配信できる静的成果物です。GitHub Pages用ブランチへ配置し、`.nojekyll`を追加します。ハッシュルーティングにより、各画面の直リンクでサーバー側の書き換え設定は不要です。

Service Workerは配信スコープごとのバージョン付きキャッシュを使います。全教材・図表示ライブラリの保存が成功してから切り替えます。他アプリのキャッシュは削除しません。
